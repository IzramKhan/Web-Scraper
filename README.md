# Web Scraper

A basic Python web scraper that collects book titles and prices from
[books.toscrape.com](https://books.toscrape.com/) and saves them to a CSV file.

## Version 1

- Downloads the first page of the site
- Extracts each book's title and price
- Prints them and saves them to `books.csv`
